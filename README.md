# Icons-Banners
BCTC Banners and Icons

By adding an image to this repo, you agree you are/have the creator's permission to upload image and said image to enter GPL-3.0 Licence, forfeiting their copyright into GPL.

When uploading a image to this repo, last part of the image should have the user's discord ID, their twitter username, or some other hard name info to credit the creator.

There is two restrictions when creating icons for BCTC.
* 1st: Card Dealer (Cat character with top hat) must be in the image.
* 2nd: The letters BCTC must be in the image. If artist doesn't desire to present the letters, then card dealer must be in the center and easy to see compared to rest of the image.

There are currently no restrictions for banners.
